# Кампус БГПУ — модуль общения и уведомлений

Учебный прототип по теме «Разработка модуля отправки уведомлений и коммуникации пользователей кампусной системы БГПУ».

В модуле есть три общих чата, закрытые чаты с приглашениями, счётчик участников онлайн и история переписки. Сообщения доставляются открытым вкладкам через WebSocket и сохраняются в SQLite. Профиль создаётся по имени и сохраняется в браузере. Общие чаты доступны всем демонстрационным профилям. Переписка и уведомления закрытого чата доступны его участникам.

## Запуск на Windows

В PowerShell из папки проекта с установленным Python 3.14:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn main:app --reload
```

Если в PyCharm уже настроено виртуальное окружение `.venv`, начните с установки зависимостей. Откройте [http://localhost:8000](http://localhost:8000). База `data/campus.sqlite3` создаётся при первом запуске. Путь можно задать через переменную окружения `CAMPUS_DB_PATH`. Для демонстрации запускайте один процесс Uvicorn, поскольку WebSocket-подключения хранятся в памяти процесса.

## Сценарий демонстрации

1. Откройте приложение в двух профилях браузера или в приватном окне для отправителя и обычном для получателя. Укажите два разных имени.
2. В окне получателя откройте **Уведомления**, нажмите **Включить системные** и разрешите их в браузере. Оставьте вкладку открытой. Для показа лучше использовать настольный Chrome или Edge.
3. В первом окне отправьте сообщение. Во втором окне появится непрочитанное уведомление, даже если там выбран другой чат. Системный баннер показывает автора и фрагмент сообщения. Нажатие открывает нужный чат и отмечает уведомление прочитанным.
4. Перезапустите сервер и обновите страницу. История переписки и состояние уведомлений сохранятся.

Системные баннеры работают на localhost или по HTTPS при разрешении сайта в браузере и включённых уведомлениях браузера в операционной системе. Если вкладка закрыта, сообщения по-прежнему попадают в центр уведомлений и отображаются при следующем открытии.

## Закрытые чаты

Нажмите **+ Создать** рядом со списком чатов и введите название. Скопируйте приглашение из появившегося окна. Владелец может открыть ту же ссылку кнопкой **Пригласить** в шапке чата. Ссылка многоразовая и позволяет вступить любому, кто её получил.

Откройте ссылку во втором профиле браузера или в приватном окне. При необходимости создайте профиль, затем нажмите **Вступить**. Чат появится в списке и останется доступен после перезапуска сервера. Ссылка с `localhost` подходит для проверки в двух окнах на одном компьютере.

Владелец может удалить закрытый чат кнопкой **Удалить** в шапке чата. После подтверждения у всех участников удалятся переписка и уведомления чата. Приглашение перестанет действовать.

## Администрирование

Откройте [панель администратора](http://localhost:8000/admin) и введите локальный ключ. Сервер создаёт его при первом запуске рядом с базой. Для стандартного пути базы ключ можно прочитать в PowerShell:

```powershell
Get-Content .\data\campus.sqlite3.admin-key
```

В панели можно удалить любой чат, отдельное сообщение, отдельное уведомление или демопрофиль. Удаление сообщения удаляет связанные уведомления. Удаление профиля также удаляет созданные им чаты, его сообщения, связанные уведомления и членство в других чатах. Для каждого удаления требуется подтверждение. Удалённые данные не восстанавливаются при перезапуске.

Подключение к учётным записям кампусной системы, отправка по электронной почте и бот в MAX остаются за рамками текущего прототипа.
